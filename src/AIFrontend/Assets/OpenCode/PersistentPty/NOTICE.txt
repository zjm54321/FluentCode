Official npm stable versions were checked on 2026-10-29. Packages were downloaded
only into the workspace's ignored artifacts/persistent-pty-vendor directory.
Tarball SHA-512 integrity was verified before selecting unmodified distribution
files. Exact versions, source URLs and SHA-256 hashes are in vendor-manifest.json.
No CDN, remote script, build-time download, npm install or server dependency.

index.html, terminal.css and terminal.js are AIFrontend integration code.
The renderer never receives backend URLs, authentication, WebSocket tickets,
attachment IDs or server replay cursors. Its nonce is a local view-generation
fence, not an authentication credential.
