## 完整覆盖矩阵

| 来源 | 前端交付 |
| --- | --- |
| Desktop Bridge | 使用 `opencode.qol.desktop-bridge` 协商 v1；接通已有模型收藏与 Billion 自动发现，保留能力检查、来源归属与发现确认。 |
| OMO 会话预设 | 保留已完成的真实会话绑定读取，增加按精确名称应用的入口；明确只影响以后新建的子会话。服务端没有名称列表或解除绑定方法，界面采用名称输入，不伪造选项或清除操作。 |
| OMO 子任务、问题与 To Do | 继续使用公开会话、表单、To Do 和事件数据；补真实 builtin 插件身份夹具。不读取 TUI 本地状态文件来冒充远程能力。 |
| Billion Context | 保留已确认实例的当前会话只读数据；展示最佳上下文参考及来源，补充可安全投影的缓存账本数值。增加显式打开本地官方控制台的入口，说明控制台可浏览该实例的其他历史。会话压缩开关保持不可用。 |
| 加密内容清理 | 用 `opencode.qol.clear-encrypted-contents/clear` 的真实 RPC 增加当前会话操作、确认、固定安全反馈、变更计数及消息刷新；原有服务端 slash command 仍走通用命令机制。 |
| 持久 PTY | 新增独立于 `coreShell.Info` 的适配，使用 `experimental.persistentPty` 能力、认证 API、一次性连接票据和 WebSocket。支持真实终端渲染、输入、尺寸、角色与会话生命周期；接管必须是显式动作，关闭面板只断开连接。 |
| 图片与 Session Reader | 用真实工具输入/输出形状补通用工具结果、历史和图片预览验证，不另造插件接口或独立面板。 |
| Bundled MCP、模型策略、GPT Taste | 沿用标准 MCP、模型目录和服务端行为；不从 `features.server` 推断插件 RPC 可用。 |
| 浏览器 | 保留已经完成的 v4 渲染器、隧道、inspect、Lighthouse、跨域选择和 Chrome/WebView2 功能，不重复建设。 |

## 实施与验证约束

- 预设和清理操作必须绑定实际来源、客户端、目录和会话；读取与写入分别处理，传输结果未知时不自动重放。
- PTY ID 与 Shell ID 不混用。票据及认证留在宿主传输层，不交给终端 WebView；角色以服务端结果为准，撤销来源、切换会话和迟到消息均有归属检查。
- Billion 原生投影继续只读当前会话的白名单元数据，未知数值不补零，不读取块摘要、提示正文或隐式扩展到其他会话。控制台入口指向已经确认的本机实例，不能经过会话浏览器的服务端网络隧道。
- UI 由 GPT-6.1 Sol designer 负责；插件操作、PTY、Billion 数据投影与通用夹具分离文件范围。协议与控件接口确认后再接线，不用占位调用伪装完成。
- 每条实现线先执行相关生产方法/传输/渲染专项检查。汇合后运行本阶段整体验证与受影响的原生构建发布；复用同一输入仍然有效的证据，失败项定向修复。

实际通过的检查、证据位置、失败修复闭环与分项提交见 [最终验收记录](../validation/2026-10-29-qol-plugin-frontend.md)。
