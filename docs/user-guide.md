# FluentCode 用户指南

本指南介绍 FluentCode 的界面结构、日常操作与功能使用方法。

---

## 1. 首次运行与服务连接

初次打开 FluentCode 时，如果尚未配置 OpenCode，应用会显示欢迎页。页面提供三种连接方式：

### 1.1 WSL 自动发现
如果 OpenCode 运行在当前系统的 WSL 分发版中：
1. 在“连接方式”单选框中选择“WSL 自动发现”。
2. 从“WSL 发行版”下拉框中选择对应的 Linux 分发版；若未看到目标发行版，点击旁边的“刷新 WSL 发行版”。
3. 点击下方的“连接 OpenCode”按钮。应用会自动通过所选发行版读取服务信息并建立连接。

### 1.2 远程地址认证
连接远程或手动运行的 OpenCode 服务：
1. 选择“远程地址 + 用户名 + 密码”。
2. 在“远程地址”栏输入服务根地址，例如 `https://example.com:4096` 或 `http://localhost:4096`（地址末尾不需要加 `/api`）。
3. 填入用户名与服务密码。密码使用 Windows DPAPI（CurrentUser 范围）加密保存在本机，不以明文存储。
4. 点击“连接 OpenCode”。应用将验证连接并保存设置。

### 1.3 远程配对链接
使用服务端生成的一次性 V2 配对链接：
1. 选择“远程配对链接”。
2. 将链接完整粘贴到“远程配对链接”输入框中。
3. 点击“连接 OpenCode”。应用会向服务端兑换链接并在验证通过后保存配置。
4. 若兑换后需要放弃，可点击出现的“放弃配对结果”按钮。

连接成功后，欢迎页会自动关闭并进入工作区。之后如果需要更改连接或断开，可以在“设置 › 账号与连接”中修改。

## 2. 界面布局与导航

FluentCode 的主界面采用三栏结构，并使用与标题栏合并的单行标签栏：

```
┌────────────────────────────────────────────────────────────────────────────────────────┐
│ [⌂ 首页] [ 会话 1 × ] [ 会话 2 × ] [ + ]                             (拖动区)  — □ ✕   │
├─────────────────┬────────────────────────────────────────────────┬─────────────────────┤
│   左侧面板      │                  中央对话区域                  │      右侧面板       │
│                 │                                                │                     │
│ 子智能体树      │ 消息时间线 (Transcript)                        │ 会话标题与 ID (可复制)│
│ ├─ subagent-1   │ ├─ [用户消息气泡]                              │                     │
│ └─ subagent-2   │ ├─ [思考中... 环形进度]                        │ 快速访问 (WSL / 本机) │
│                 │ ├─ [处理过程: 4 ✓, 0 ✗]                        │ [目录] [VS Code] [终端]│
│ 终端分组        │ └─ [工具调用详情]                              │                     │
│ ├─ pty-1 (运行) │                                                ├─────────────────────┤
│ └─ shell-1      │────────────────────────────────────────────────│ 上下文指标 (用量/上限)│
│                 │ 输入区 (Composer)                              ├─────────────────────┤
│                 │ [智能体 ▾] [模型 ▾] [思考程度 ▾]               │ 实时待办任务 (To-Do)│
│                 │ 输入消息... (@ 提及, / 命令, ! Shell)  [发送]  │ [✓] 步骤 1          │
│                 │ (子会话时显示: [返回] [停止])                  │ [ ] 步骤 2          │
│                 │                                                ├─────────────────────┤
│                 │                                                │ 工作目录与版本页脚  │
└─────────────────┴────────────────────────────────────────────────┴─────────────────────┘
```

- **单行标签栏**：窗口最左侧固定显示“首页”标签（不可关闭）。右侧依次显示打开的会话标签，点击可切换，点击标签右侧的 ✕ 可关闭当前标签。标签栏空白处可直接拖动窗口。
- **左侧面板**：显示当前会话派生出的子智能体（Agent Tree）以及当前会话拥有的终端列表（PTY 终端与 Shell 输出）。 子智能体列表只显示当前主智能体可以调用的子智能体（如 Brainstorm 显示 Ideator、Scout、Red-Team，Scribe 显示 Doc-Researcher、Drafter、Fact-Checker、Typesetter），切换主智能体后立即刷新；已在当前会话运行过或正在运行的子智能体始终保留。未选择主智能体或没有委派规则时显示全部。
- **中央区域**：显示对话时间线与底部输入区。当进入子会话时，输入区会替换为返回原会话与停止按钮。
- **对话导航**：时间线左侧的一列短横线代表已加载的各轮提问，橙色（强调色）标记为当前所在的一轮。
  - 鼠标 / 触控笔：悬停预览该轮的提问与回复，单击跳转；聚焦后可用方向键、<kbd>Home</kbd> / <kbd>End</kbd> 选择，<kbd>Enter</kbd> 跳转，<kbd>Esc</kbd> 关闭预览。
  - 触控：点一下导航栏会在旁边展开一列较大的轮次列表（每行显示序号和提问，当前一轮带强调色标记），第一次点按只展开、不会跳转。展开后点按某一行即跳转；也可以按住手指上下拖动（可从导航栏直接拖进列表），手指下方的一轮会高亮，列表顶部同步显示这一轮的提问，松手后跳转。拖到列表上下边缘会自动滚动，便于在很长的会话中选择；拖动时向右滑出列表再松手可取消。点按列表以外的位置、再次点按导航栏或按 <kbd>Esc</kbd> 可收起列表，跳转后也会自动收起。展开的列表只在对话区域内显示，不会遮住输入区。
- **右侧面板**：显示当前会话标题与 ID、快速访问按钮（在资源管理器中打开、在 VS Code / VSCodium / Zed 中打开）、上下文 Token 用量、服务推送的待办任务清单，以及当前工作目录和连接状态页脚。
  - **轮次**：按当前会话撤回点之前已加载的提问计数（附件提问也算一轮）。历史未全部加载时显示 `≥N`，提示“历史尚未全部加载”；加载完历史后显示精确数字。切换到已有会话或重新加载后也会显示，不会为计数额外请求历史。撤回边界未知、不可读取或不在已加载窗口中时暂不显示。
- **打开设置**：在首页右下角点击“设置”，或在任意界面按快捷键 <kbd>Ctrl</kbd> + <kbd>,</kbd>，设置会作为新标签页打开。

## 3. 会话与消息交互

### 3.1 步骤分组与思考过程
- **步骤折叠**：单次回合内的连续思考与工具调用会自动收纳到“处理过程”分组中，头部标明成功（`n ✓`）与出错（`m ✗`）的数量，点击可展开或折叠。
- **详情一律在浮层中查看**：思考、To Do、带图片的工具结果、上下文压缩摘要等需要点击才能看到的内容，都在共享的详情浮层中显示，不会在时间线行下展开。只有“处理过程”分组、用户长消息与消息内代码块保留就地展开；终端条目点击后打开终端浮窗。
- **思考过程**：模型生成的推理文本支持 Markdown 排版。进行中时始终保持“思考中…”、环形进度条与预览的单行显示，不自动在行下展开；已打开的详情浮层随生成内容更新。
- **进行中指示**：时间线中进行中的思考、工具（含后台终端与后台子智能体）以及通知行，右侧都显示同一种进度环：16 像素、2 像素粗的强调色四分之三圆弧，位于行最右侧的同一列，上下行对齐，并且所有进度环同步转动。系统或应用关闭动画后，进度环停止转动，但仍保持可见。后台任务用“后台”标签与“后台运行中”文字区分，不另换颜色；后台任务也不再显示启动调用的毫秒数，以免被误读为任务已运行的时间。
- **用户长消息折叠**：超过两行的用户消息默认折叠为双行紧凑气泡，点击右侧的箭头按钮即可展开查看全文。

### 3.2 工具调用详情
- **悬停预览**：鼠标悬停在工具条目上方约 1.5 秒，会显示包含调用参数与输出摘要的浮层。浮层显示在条目下方（下方放不下时在上方），并与条目之间空出相邻的一整行：鼠标移到上一行或下一行时会落在那一行上，而不会碰到当前浮层；需要查看浮层时直接把鼠标移入即可。切换浅色 / 深色（应用设置或 Windows 主题）后，已打开和之后打开的浮层都会立即使用新主题。
- **大图详情视图**：点击工具条目或按 <kbd>Enter</kbd> 可打开居中大视图。视图大小随内容收缩：宽度取内容的自然宽度（至少 560，最多为窗口的 80%），高度取内容高度（至少 160，最多为窗口的 80%），更长的内容在视图内滚动；打开后宽度保持不变，内容更新时只会变宽。代码差异（并排两栏）、浏览器页面与图片结果始终使用窗口 80% 的宽度。长文本会自动换行并分段加载，代码编辑支持在统一视图（Unified）与并排视图（Side-by-Side）之间切换。按 <kbd>Esc</kbd> 或点击遮罩即可退出。
- **思考、提问、To Do 与图片**：与普通工具行使用同一个详情浮层；悬停预览，点击或按 <kbd>Enter</kbd> / <kbd>Space</kbd> 固定打开，左侧显示选中条，按 <kbd>Esc</kbd> 关闭。思考文本、问题与回答、To Do 列表（悬停时只列出前几项）以及工具返回的图片均在浮层中显示，不在时间线行下展开；待回答的问题仍在输入区作答。
  - 思考：悬停预览显示前 8 行（生成中显示最新的 8 行），固定打开后显示完整内容；完成后标题栏显示思考用时，加密的思考内容会给出说明。
  - 上下文压缩：有摘要时，说明行下方会出现一行“压缩摘要”，摘要全文同样在详情浮层中以 Markdown 显示。
  - 提问：每个选项前用勾选标记表示是否被选中，推荐的选项显示“推荐”标签，自行输入的回答单独显示；悬停预览只列出已选的选项。等待回答、已跳过等状态会单独标出，超过 1 分钟的用时以“N 分 M 秒”“N 小时 M 分”显示。
- **会话工具**：“读取会话”和“会话列表”等会话、终端（pty）类工具的条目右侧不再显示原始工具名，改为显示被读取会话的标题或搜索关键词。打开详情时，“读取会话”按轮次显示用户与助手的消息，工具调用合并为一行摘要（固定打开后可逐项查看）；“会话列表”逐行显示会话标题、ID 与更新时间。内容无法识别时回退为通用的参数 / 输出视图。
- **子智能体汇报（`task_report`）**：进度显示“汇报进度”，问题显示“上报问题”（警示色），未识别的类型显示“汇报”；行内只显示消息首行。详情显示类型、完整消息以及“已排队”或“已排队（未唤醒主会话）”，并注明“主会话尚未确认处理”。排队成功不会把子任务标为完成。
- **子智能体状态与取消**：`task_status` / `task_cancel` 支持新的 `sessionID` 和旧的 `task_id`；已知子会话优先显示智能体与标题。未知或未确认（`unconfirmed`）的状态不会显示为已确认完成。

### 3.3 子智能体查看与返回
- 点击时间线中的子代理工具行，会弹出一个独立的只读小窗口，用于快速查看该子任务的最新消息。
- 点击只读小窗口右上角的最大化按钮，或在左侧子智能体树中点击对应项，当前标签页将切换进入该子会话。
- 进入子会话后，底部输入区会替换为底栏，点击左下角的**“返回”**按钮即可随时退回主会话。
- 主会话收到 `<subagent-update>` 时，时间线复用现有提示行显示“@智能体 汇报进度 · 消息摘要”或“@智能体 上报问题 · 消息摘要”，使用该智能体的图标与颜色；问题汇报使用警示文字。浮层保留完整消息，并提供“打开子智能体会话”。格式异常时仍显示普通“内部自动消息”；汇报不是完成通知。

### 3.4 消息上下文菜单
在时间线消息上点击鼠标右键、按下键盘菜单键或触屏长按，可呼出操作菜单：
- **复制整段**：复制当前消息的全部文本。复制完成后图标会临时变为对勾进行提示。
- **复制代码**：在代码块区域点击时可用，只复制纯代码内容。
- **撤回 / 恢复撤回**：回滚或重做该轮交互。

## 4. 输入区使用技巧（Composer）

输入区位于主工作区底部，用于组织和提交任务输入：

### 4.1 选择器工具栏
输入框左下方提供三个快捷下拉菜单：
- **智能体选择器**：切换当前会话所用的 Agent。 每个主智能体和子智能体都有各自的图标与颜色，在选择器、左侧子智能体树、时间线和 `@` 提及中保持一致；同一主智能体的团队使用相近色系，后端配置了颜色时以后端为准。
  - 后端启用可选的 `validator`（`alvin/validator@1.0.0`）后，显示名为 **Validator**，使用检查清单图标；它是执行测试的专用子智能体。
- **模型选择器**：选择当前服务支持的底层大语言模型。
- **思考程度（Effort）**：调节推理模型的思考深度（low / medium / high）。

### 4.2 字符触发器
- **`@` 提及**：键入 `@` 呼出候选项，可模糊搜索当前服务提供的子智能体或 Skill，选中后将标识插入输入框。子智能体按当前主智能体的委派权限筛选：最后一条匹配规则生效，支持 `*`，被拒绝的候选不显示；切换主智能体会刷新候选。Skill 不受此委派筛选影响。
- **`/` 命令**：在输入框开头键入 `/` 呼出斜杠命令菜单，支持按 <kbd>Tab</kbd> 自动补全命令名称。
- **`!` Shell 执行**：在输入框开头键入 `!`，输入框进入 Shell 模式。按 <kbd>Enter</kbd> 直接在服务端当前工作目录执行该命令，按 <kbd>Esc</kbd> 可恢复之前的文本草稿。

### 4.3 附件上传
- **粘贴截图**：在输入框内按 <kbd>Ctrl</kbd> + <kbd>V</kbd>，剪贴板中的图片会自动转换为附件显示在输入框上方，同时在光标处插入 `[Image N]` 芯片（与 TUI 写法一致）。编号在本条消息内从 1 递增，删除后不重排；退格删掉芯片会同时移除附件（<kbd>Ctrl</kbd> + <kbd>Z</kbd> 一起恢复），在附件条上点 × 也会同时删掉正文里的芯片。
- **拖拽文件**：支持从 Windows 资源管理器直接拖入图片、PDF 或文本文件。
- **限制说明**：单次最多添加 10 个附件，单个附件不超过 10 MiB，整条请求大小不超过 28 MiB。

### 4.3.1 链接芯片
- **自动识别**：粘贴单个 http / https 链接时，输入框会把它显示为“图标 + 简称”的芯片，例如 `oh-my-opencode-slim #1591`（Issue）、`opencode #4821`（PR）、`p !17`（GitLab MR）、`opencode@d38b26e`（提交）、`index.tsx:1224-1271`（文件 + 行）、`opencode v1.4.0`（版本）。普通网站显示“域名/…/最后一段”，本机和内网地址带端口。简称最多 32 个字符，过长时中间省略。
- **发送和复制都是完整链接**：模型收到的永远是原始链接；复制含芯片的选区时也还原为完整链接，粘回输入框会再次变成芯片。
- **编辑**：<kbd>Backspace</kbd> / <kbd>Delete</kbd> 一次删掉整个芯片，<kbd>Ctrl</kbd> + <kbd>Z</kbd> 恢复；刚粘贴后按 <kbd>Ctrl</kbd> + <kbd>Z</kbd> 可恢复为纯文本。想修改链接时右键选“转回文字”。光标不会停在芯片内部。
- **打开**：输入框里 <kbd>Ctrl</kbd> + 单击打开（普通单击只放光标）；会话记录里单击芯片即用默认浏览器打开，只允许 http / https。悬停可看到完整地址（用户名、令牌已隐藏）和站点信息；右键可打开、复制链接、复制为 Markdown。
- **不会转换的情况**：行内代码和代码块里的链接、`file:` / `vscode:` / `mailto:` 等其他协议、超过 2048 字符的网址。句末标点不算进链接。易混淆字符域名显示为 punycode 并带警告图标；`github.com.evil.io` 这类仿冒域名按普通网站处理。正在流式输出的消息末尾链接会在输出停止后再变成芯片。
- **站点图标与联网补全**：GitHub、GitLab、Gitee、Codeberg 使用内置图标。普通网站默认显示地球图标；在“设置 → 常规 → 链接与图片”中开启“联网补全”后，会显示该网站自己的图标（按站点缓存，失败时仍为地球）。本机、局域网和内网地址从不联网。同一页还可以把图标改为单色；高对比度下图标总是单色。

### 4.4 发送与中断
- 按 <kbd>Enter</kbd> 发送消息；按 <kbd>Shift</kbd> + <kbd>Enter</kbd> 换行。输入中文选词时按 Enter 不会触发发送。
- 输入框支持单行输入，随着内容增多会自动增高（最高 160 像素），超出后内部滚动。
- 任务执行期间，发送按钮会自动变为带强调色背景的**停止按钮**，点击即可中断当前执行。

## 5. 右侧面板功能

- **会话元数据**：顶部显示当前会话标题与 ID，点击 ID 即可复制到剪贴板。
- **快速访问按钮**：
  - **文件夹图标**：在 Windows 资源管理器中打开当前会话的工作目录。
  - **编辑器按钮**：在主机文本编辑器中打开工作目录。系统检测已安装的编辑器并提供下拉菜单，支持 VS Code（通过 WSL 远程模式直连）、VSCodium 与 Zed。
  - **浏览器与终端快捷按钮**：快速呼出会话浏览器或终端卡片。
- **上下文指标（Context Ring）**：
  - 显示当前会话已用 Token 数与模型上限的参考比例（例如 `82.3K / 1M`），并以圆环进度条显示。
  - 点击圆环可打开浮层，查看输入、输出与缓存 Token 明细。若服务关联了 Billion 上下文，浮层中还会显示压缩块的详细列表。
- **实时待办任务（To-Do）**：显示模型规划的子任务，并用状态图标标明待执行、进行中、已完成或已跳过。
- **页脚**：显示工作目录绝对路径与 OpenCode 连接版本号及状态圆点。

## 6. 原生终端与会话浏览器

### 6.1 原生终端操作
- **双击接管输入**：终端打开后默认处于防误触保护状态，键盘输入不会送入终端。**双击终端文本区域**即可接管控制权并开始键盘输入。
- **重命名终端**：选中终端后按 <kbd>F2</kbd> 键，或在终端菜单中点击“重命名…”，可为该终端指定易识别的名称。
- **关闭视图 vs 结束进程**：点击终端卡片右上角的 ✕ 仅关闭当前的查看窗口，不会终止后台运行的终端进程。如果需要彻底结束该进程，需点击专门的“结束”按钮。
- **适应窗口**：点击工具栏的“适应窗口”按钮，终端会根据当前卡片尺寸重新调整字符网格大小。
- **外观调整**：在“设置 › 终端”中可以自定义字体（默认 Cascadia Mono）、字号（6–72 pt）、光标样式（条形、方块、下划线）与调色板（Campbell、One Half、Solarized 等）。

### 6.2 会话浏览器
- 可以在“设置 › 浏览器”中选择使用内置 WebView2 引擎或连接外部 Chrome。
- 会话内的网页请求通过服务端的网络隧道转发，网页中访问 `localhost` 指向服务端开发环境。
- 服务端端口未监听或隧道连接失败时，页面会显示目标地址和服务端错误；不会改用桌面网络访问。
- HTML 文件预览通过隔离的虚拟地址读取服务器文件，可加载预览文件所在目录及子目录中的相对图片、CSS、脚本和字体。保留行内及同目录脚本，但不允许外部网络请求、工作线程、弹窗或下载；链接不会在预览中跳转。HTML 最多 64 MiB，单个资源最多 5 MiB，每次渲染资源合计最多 96 MiB、256 次资源请求。
- Remote、WSL 和本地连接均通过 `fs.read` 读取预览文件。明确请求预览的文件即使位于会话目录外，也会以该文件的父目录作为服务端读取位置；页面资源只能读取此目录树，不能自行更换读取位置或使用 `..` 越界。符号链接仍由服务端的真实路径边界检查约束。服务器拒绝读取时，“渲染”和“源码”都会显示错误原因，不会留下空白页。
- 浏览器工具栏只有一行，从左到右依次是导航（后退、前进、刷新）、地址栏、页面工具（选择元素、框选、在外部浏览器打开）、“更多”和关闭。
- 地址栏显示页面网址，其中域名或文件名最醒目，页面标题显示在地址栏右侧。鼠标悬停可查看标题、完整地址和访问位置；单击地址栏可编辑网址。访问 `localhost` 这类地址时，地址栏左侧会标出“WSL 网络”或“远程服务器”，说明这个地址是在哪里访问的。
- 文件预览的地址栏显示服务器路径并标出“服务器文件”。预览没有后退和前进，刷新会重新读取文件。“渲染/源码”标签（两者内容不同时才显示）、“在编辑器中打开”和“在文件资源管理器中显示”都在工具栏这一行；窗口很窄时，后两项会移到“更多”菜单。
- 源码视图带行号，并跟随当前主题和代码配色。“自动换行”按钮可切换长行的显示方式，设置在应用下次启动前一直有效；开启后只能在单行内选择文本。
- 提供页面性能与无障碍分析功能。

## 7. 系统通知与后台托盘

- **长任务完成通知**：当后台会话执行完毕回到空闲状态时，Windows 系统会弹出通知横幅。点击通知可激活并直接跳转到该会话。若当前会话就在前台窗口可见，则会自动静默不打扰。
- **权限审批与问题回答**：当模型请求执行敏感操作（如执行危险命令或修改文件）或提问时，Windows 通知横幅中会直接附带“单次允许”、“始终允许”、“拒绝”按钮或输入文本框。用户无需切回应用主窗口即可完成确认。
- **任务栏状态**：任务栏图标上的进度条与角标会随任务状态改变：正在执行显示进度，需要用户确认时显示黄色感叹号角标，完成时显示绿色对勾，出错时显示红色叉号。
- **最小化到系统托盘**：在“设置 › 常规”中开启“关闭窗口时最小化至系统托盘”后，点击窗口的关闭按钮会将应用隐藏到系统托盘常驻，长任务与网络连接不会中断。在托盘图标右键菜单中选择“退出”可彻底退出程序。
