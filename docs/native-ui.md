# Native OpenUI Lang v1

The opencode-qol `native_ui` tool accepts `{source, title?}`. Server validation uses official MIT `@openuidev/lang-core` **1.1.0**, with a Zod catalog preserving OpenIntelligentUI's names and positional prop order. Success is a short acknowledgement; the program remains in tool `state.input` for history replay.

The always-on `native_ui` description is short (**258** o200k_base tokens) and tells the model to load the bundled **native-ui** skill before its first call. That skill (opencode-qol `kernel/defaults/skills/native-ui/`) carries the language, behavior/safety/design guidance, worked examples, error recovery and the full component catalog generated from the same schema the validator uses; validation diagnostics direct the model there. The former `native_ui_reference` tool is removed. The tool and skill are denied to non-primary agents. The generated catalog is `fluentcode-native-ui@0.2.0`: the 54 upstream names except HtmlView plus native Video, Audio and ImageGallery (57 total).

## Contract

`src/FluentCode/Services/NativeUi/catalog.json` is the embedded byte-identical copy of QoL's generated manifest (`kernel/plugins/native-ui/scripts/generate-catalog.ts`). It supplies component/prop order, JSON Schema types, reactive flags and resource limits. The server's focused Bun test checks equality between the two lanes.

The C# port implements the complete lexer/Pratt expression grammar, assignments, references/forward references, root/fallback entry, schema-aware lowering, partial-input auto-close, comment/fence handling and the streaming completed-statement watermark. The shared corpus compares complete parse JSON, evaluated defaults and streaming snapshots against lang-core 1.1.0. Duplicate definitions, unresolved/cyclic references and schema errors follow the official parser.

The local runtime has `$variables`, reactive `$value` assignments, ordered `Action([...])`, `@Set`/`@Reset`, arithmetic/comparison/boolean operators, ternaries, member/index access and the core built-ins (including Count, Sum, Round and Each). Each captures iterator values for deferred actions. Query/Mutation/defaults are parsed; no tools or network are invoked. Their cards/actions say **未支持**. @Run stops an unsupported action sequence. @OpenUrl and Link allow only absolute http(s) URLs and show the **entire URL** in a confirmation flyout before the system browser opens. Cancelling stops the remaining ordered actions. Native flyouts suppress terminal airspace while open.

Limits in both lanes: **65,536 source characters, 4,096 nodes, depth 64, 16,384 string characters**. Expansion and evaluation are bounded as well as lexing. URL data is restricted to http(s). Cards have no script/reflection/HTML/file capability. Images never fetch automatically: their full HTTPS URL and a **点击加载** button appear first. Explicit loads are bounded to 8 MB/30 seconds/5 redirects, with HTTPS checked at every redirect. The reused Markdown presenter has an explicit sandbox policy: no inherited transcript image scope, link/attachment chips or Mermaid browser rendering.

## Native UI and composer

All catalog components share the Fluent styling in `Pages/OpenCode/NativeUi/NativeUiTheme.cs`; `NativeUiTheme.Components.cs` contains only structural helpers, not duplicate colour/icon tokens. Compact cards are left-aligned at up to 480px. Trees containing Table, Chart, Carousel, Map, Grid or Image (or multi-card Rows) stretch up to 808px. Nested cards use 4px corners and 12px default padding; badges use 20px pills. Tables use 32px headers, 36px divided rows without zebra striping, and right-aligned tabular numbers. Charts use the six-slot light/dark data palette. Input/TextArea, segmented controls and radio tiles share the native control theme. Structural-path reconciliation retains input/caret and slider control identity during state updates. Ask **@designer** with the relevant renderer/theme file and visual goal for layout/styling changes.

`Button` and `IconButton` accept `size: sm|md|lg` in their positional contracts: 32/40/48px high. Buttons fill Grid cells and button-only Rows. Without an explicit size, short-label calculator keys derive their height from their column width: `clamp(width * 0.8, 40, 56)`. Explicit size takes priority. Neutral soft buttons overlay a small amount of foreground colour, so they are slightly lighter than a dark card and slightly darker than a light card; stock focus/hover/pressed/disabled states remain native.

- Chart supports bar/line/area/pie/donut/scatter and number/currency/percent formatting, including stacked bar/area, via LiveCharts2 2.0.5 (MIT). Metrics compose Card/Title/Caption; upstream has no separate Stat/Metric component.
- Table uses WinUI.TableView 1.5.1 (MIT), with native sortable/resizable columns and arbitrary component cells. SegmentedControl and radio pills use CommunityToolkit Segmented 8.2.251219 (MIT).
- Forms include TextArea, radio variants, CalendarDatePicker, timer (pauses on unload), IconButton and keyboard-accessible Pressable. Box/Grid/Form/Spacer/Carousel/Popover use native panels, scrolling and flyouts.
- List/Quote/Code/Flashcard/Celebration and Canvas/XAML drawing primitives are native. Math intentionally displays formula source in v1. Ninety Icon names map to Segoe Fluent Icons; unknown names are omitted rather than silently replaced with a different icon.
- Map/MapMarker initially show static location cards and confirmed OpenStreetMap links. **加载地图** creates a Mapsui.WinUI 5.1.0 (MIT) viewport: pan/zoom, labelled circular markers, reactive selection, fit-to-markers and optional ordered polyline (not routing). Marker glyphs appear in the location list; viewport labels use the shared Microsoft YaHei UI font because Skia does not apply XAML's CJK fallback. AI coordinates are always WGS-84; AMap converts China points to GCJ-02. Settings offers OSM (default), AMap, Baidu, TianDiTu user key and HTTPS custom XYZ plus mandatory attribution. Baidu converts WGS-84→GCJ-02→BD-09→BD09MC for both markers and polylines, and uses its native 256px grid: origin (0,0), signed rows increasing northward, resolution `2^(18-z)` metres/pixel and zoom clamped to 3–19. It does not use EPSG:3857. Current HTTPS Baidu raster requests need no AK; Baidu terms and authorization limits apply. No Azure dependency.
- Map attribution remains visible. OSM requests use a FluentCode User-Agent, HTTP expiry/ETag/Last-Modified caching (7-day default), no cookies, no prefetch/offline region downloads and HTTPS-only redirects. Respect each provider's licence/usage limits; keys do not grant redistribution rights. TianDiTu credentials are DPAPI-encrypted references, never plaintext settings or embedded keys. Custom providers must supply their own URL and attribution; changing source requires a new click. Tile failure keeps the usable location list.
- Video/Audio show their full HTTPS URL before a click loads up to 128 MB into a native MediaPlayerElement. System-supported codecs only; native transport controls, explicit video full-window toggle, no autoplay, pause on unload. ImageGallery loads 1–12 images (8 MB each) into a large FlipView and a full-size scrollable viewer. Redirects must stay HTTPS and cannot carry user-info credentials. Images/media use no cookies. Gallery dialogs suppress terminal airspace while open.
- YouTube loads its thumbnail only after a click; clicking the thumbnail/watch button opens the existing current-session in-app browser workspace, with transcript origin/session guards. No WebView/player is embedded in the card. SearchImage remains a static native search card and confirmed external link.

`native_ui` tool parts are answer cards outside generic collapsed tool groups. `tool.input.delta` retains a placeholder even when a JSON prefix already looks complete; the final `input.ended` marker permits rendering. Parse/validation failures are compact error cards. Tool progress/success, transcript virtualization and reopening the same session retain variables, form values and flashcard face **during the same app run**, keyed by globally unique message part ID and exact source. The app-run store holds plain values only, not controls/timers/host callbacks. Restarts return to declared defaults; nothing is written to disk.

@ToAssistant is only a user intent. The page verifies the live transcript/source/session and clean composer, preserves existing drafts, reconciles the ordinary editor, then invokes **RequestComposerSubmission**. The normal shared interaction lease/send workflow remains the only transport route. An agent working receives **queue** delivery; unavailable queue, permission/protection, stale origin, shell mode or existing draft blocks the intent. Command-leading `!`/`/` messages cannot turn a card into code execution. Context/form-state data accompanies the ordinary prompt as labeled JSON, not a separate RPC call.

## Remaining OIU differences

- `HtmlView` is excluded. Query/Mutation/@Run execution and extra upstream pure functions remain unsupported; parsed defaults still render.
- `Math` displays TeX source instead of KaTeX typesetting. `Icon` uses the bounded native mapping rather than all Lucide names; its default is Fluent 16px rather than OIU 18px.
- `Image` uses explicit HTTPS loading, not automatic fetching. `SearchImage` has a safe search preview/link, not fetched search results (`fit` has no loaded image to affect). YouTube plays in the existing in-app browser, not an embedded card player; thumbnail loading is explicit.
- `Map` has real geographic tiles, native markers and ordered polyline; not turn-by-turn routing. Baidu/AMap/TianDiTu remain subject to provider terms, authorization and network availability; TianDiTu needs a user key. Custom XYZ assumes standard Web Mercator. Video/Audio are bounded downloads rather than live/adaptive streaming; formats depend on Windows codecs.
- `Box` percentage lengths stretch in the parent rather than implementing CSS percentage measurement. Native layout is not a CSS flex engine.
- `Carousel` provides native scrolling and previous/next navigation without CSS scroll snapping. `Flashcard` preserves face/state without a 3D flip; `Celebration` uses bounded in-card native particles, not full-page browser confetti.
- `List.timeline` uses native marker rails rather than CSS line geometry. Standalone `ListItem.marker` is not shown outside a List. Slot/quote text uses native wrapping, not the full upstream inline Markdown styling.
- `Svg` and its primitives are bounded native geometry with numeric transforms, not browser SVG/CSS/font layout. Inputs, text sizes, pills and table interactions deliberately follow WinUI/Fluent equivalents.
- Card/form state survives virtualization and same-part replay only within the current app run; restarting returns to declared defaults.
