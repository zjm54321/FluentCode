# Critical test suite

On 2026-10-30 the suite was pruned to 25 critical entries: `opencode-auth/run.ps1`, `opencode-connection/run.ps1`, `opencode-pairing/run.ps1`, `opencode-event-sync/run.ps1`, `message-pagination/run.ps1`, `opencode-view-ack/run.ps1`, `opencode-observations/run.ps1`, `notification-form/run.ps1`, `opencode-composer/run.ps1`, `opencode-composer-hookup/run.ps1` (default only, no `-NativeOnly`), `opencode-commands-attachments/run.ps1`, `opencode-queued-withdraw/run.ps1`, `opencode-plugin-mutations/run.ps1`, `opencode-session-controls/run.ps1`, `opencode-session-ui-state/run.ps1`, `opencode-session-return/run.ps1`, `opencode-capabilities/run.ps1`, `opencode-browser-engine/run.ps1`, `browser-runtime/run.ps1`, `opencode-browser-settings/run.ps1`, `desktop-bridge-qol/run.ps1`, `opencode-persistent-pty/run.ps1`, `opencode-persistent-pty-transport/run-backend.ps1`, `browser-runtime/runtime.test.mjs`, and `browser-runtime/audit.test.mjs` (all paths relative to `tests/`).

From WSL at the repository root, plan with `python3 tests/run-suite.py --root "artifacts/prune-verify-$(date -u +%Y%m%dT%H%M%SZ)"`; add `--execute` to run sequentially. The root must be new. Each runner gets isolated logs/temp and, where supported, `-EvidenceRoot`; the driver stops if tracked or nonignored untracked candidate files change. The two Node tests use the bundled `artifacts/browser-runtime/node.exe`. Windows PowerShell 7, .NET 10 and the retained runners' cached dependencies are required; this does not build or publish the main application.

Historical runner paths and results elsewhere in the documentation describe earlier evidence, not additional current suite entries. The inert conversation-view host now lives in `tests/opencode-session-return/ConversationView.TestHost.cs`; the persistent-PTY dependency build helper now lives in `tests/opencode-persistent-pty/BuildNativeTerminal.ps1` and is not a separate suite entry.
