# QOL 插件前端整合验证（2026-10-29）

## 完成功能

| 插件或能力 | 前端整合 |
| --- | --- |
| Desktop Bridge | 统一使用 `opencode.qol.desktop-bridge`；原有模型收藏与 Billion 自动发现恢复到实际注册的 v1 接口。发现仍须确认本机实例，不扩大通用 RPC 白名单。 |
| OMO 会话预设 | 当前会话可按完整名称应用预设。名称原样发送，仅影响以后新建的子会话；没有伪造名称列表、解除绑定或全局配置操作。成功后通过现有会话读取路径刷新。 |
| 加密内容清理 | 当前会话提供明确确认、结构化变更计数及安全反馈；确认说明服务器会先停止执行。已接纳的清理失效全部匹配历史窗口和旧执行状态，并重新读取；离开后返回同一会话也会使用新绑定刷新，不发布旧提示或改动草稿。 |
| 插件写入保护 | 本地保护绑定来源、会话、目录和具体操作。真正结果未知时阻止相关继续执行；手动确认只解除精确匹配的本地保护，不重试、不宣称服务器结果已确认。保护可在同一端点重连后核对。 |
| 持久 PTY | 独立于 coreShell 的会话终端列表、真实 VT 画面、键盘/IME、选择复制、连接与角色状态。默认观察，显式接管或启用输入；关闭只断开查看，源撤销、切页和目录变化会释放连接。 |
| PTY 渲染与传输 | 认证和一次性票据留在宿主；按字节恢复 checkpoint、回放和 UTF-8 输出，并等待渲染消费确认。重连使用新快照/票据，不重发输入；控制权丢失立即停用输入，尺寸只能显式请求。 |
| Billion | 原生界面展示最佳上下文及来源、独立的原始参考、缓存命中/未命中归因和 token 经济账本。保留未知值和有符号净值，不把数值说成金额。官方本机控制台入口须确认，明确告知可浏览该实例的其他历史。 |
| 其他修改插件 | 增加真实 builtin OMO、无参数清理命令、两种图片生成结果、图片模型列表、Session Reader 和 PTY 工具历史的通用投影夹具。模型策略、GPT Taste 和 Bundled MCP 继续使用标准目录、服务端及 MCP 路径。 |

离线终端资源为固定的 xterm 6.0.0 / addon-fit 0.11.0，附版本、来源、完整性与许可证记录。终端 WebView 限制为本地资源，不向 JavaScript 提供票据或凭据。当前渲染范围为 2–1000 列、1–1000 行，checkpoint 上限 8 MiB；超出时明确显示不可用，不改变服务器尺寸或无限重连。较大输出按不超过 1 MiB 的原始字节块依次消费。
